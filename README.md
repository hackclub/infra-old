# Hack Club Infra (deprecated)

This repo is no longer used as a ticketing system for infra; we have newer systems in place.

Are you part of the YSWS team and need access to something? File an infra ticket at [hack.af/infraticket](https://hack.af/infraticket)

Not part of the YSWS team? Ask your HQ POC (point of contact) or in [#hq-engineering](https://hackclub.enterprise.slack.com/archives/C05SVRTCDGV), and we can help you out or at least point you in the right direction.
